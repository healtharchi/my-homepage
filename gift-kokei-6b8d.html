後継者AI壁打ちプロンプト集

こんにちは、HEALTH ARCHIのHIDE（佐野英人）です。一級建築士として設計・現場監督を17年やり、今は建設会社の経営を支える仕事をしています。LINE登録ありがとうございます。

このページは、家業を継ぐ人・継いだばかりの人（次世代・二代目）のための「AI壁打ちプロンプト集」です。

後継者の悩みは、技術や知識より「人」のことが多い。先代が首を縦に振らない。古参の職人が新しいやり方を受け入れてくれない。会社の数字は見せられたけど、正直よくわからない。そして、それを誰にも相談できない。

私は『社長が現場を降りる日』という本を書きました。そこで一番伝えたかったのは、「全部ひとりで背負わなくていい」ということです。このプロンプト集は、その「相談相手」をAIに肩代わりさせるための道具です。深夜でも、誰にも気をつかわず、頭の中を整理できます。

先に、大事なお願い（30秒）
AIが返すのは「考えを整理する相手」であって、正解ではありません。特に、会社の数字・お金・法律・人事に関わる判断は、AIの言葉を鵜呑みにせず、最後は税理士・社労士・先代など、生身の人に確認してから動いてください。AIは「考えを前に進めるための壁打ち相手」。決めるのは、あなたです。
使い方（はじめての方へ）
  1. AIアプリかサイトを1つ用意する（Gemini / ChatGPT / Claude のどれか・無料で始められます）
  2. 下のプロンプトの「コピー」ボタンを押す（枠ごとコピーされます）
  3. 貼り付ける
  4. 文中の【　】の部分を、自分の状況に書き換える（中の例文を消して、自分のことを書くだけ）
  5. 送信 → 返ってきた内容に「もっと具体的に」「先代の立場でも考えて」と追加で頼むと、どんどん深まります

会社の数字や決算書を扱うときは、社名・個人名・口座番号などは伏せてから貼ってください。

プロンプト1｜先代を説得する「伝え方」を一緒に考える

枠をコピーして、【　】の中を自分のことに書き換えて送るだけ。

あなたは、家業を継ぐ後継者の相談相手です。私がやりたいこと（変えたいこと）を、先代（創業者・親）に反発されにくい形で伝えるにはどう話せばいいか、一緒に考えてください。まず先代がなぜ反対しそうかを先代の立場で3つ想像し、そのうえで「先代の功績を立てながら」提案する言い方を示してください。一度で通そうとせず段階を踏む進め方と、私が実際に言えそうな短いセリフの例も2〜3パターン出してください。

変えたいこと・やりたいこと：【現場の写真や日報をアプリで共有したい。でも先代は「電話と紙で十分だ」という考え。職人の高齢化で、このままだと回らなくなる不安がある。 ← この【　】の中を、自分の状況に書き換えてください】

プロンプト2｜古参の職人さんへの「新しいやり方」の伝え方

あなたは、人の気持ちがわかる現場経験の長い相談相手です。私（若い後継者）が、ベテランの職人さんに新しいやり方を受け入れてもらうにはどう伝えればいいか、一緒に考えてください。「教わる姿勢」を保ちながらこちらの提案も通す伝え方で、ベテランの経験とプライドを否定しない言い回しにしてください。いきなり全員に広げず味方を1人作る進め方と、現場で実際に言えそうな短いセリフの例も出してください。

受け入れてほしいこと・相手の様子：【作業の記録をスマホで写真に残してほしい。でも「昔はそんなもの無くてもやれた」と言われがち。本当はその人の腕を一番尊敬している。 ← この【　】の中を、自分の状況に書き換えてください】

プロンプト3｜会社の数字を、やさしく解説してもらう

あなたは、中小建設会社の数字にくわしい、教え方のうまい相談相手です。私は経営の数字が得意ではない後継者です。下のことについて、何を意味しているのか、良いのか悪いのか、まずどこを見ればいいかを、やさしく教えてください。専門用語は必ずやさしい言葉に言いかえ、「この数字が悪いと現場の何に影響するか」を具体的に説明し、私が次に確認すべきこと・税理士に聞くとよいことを最後にまとめてください。

聞きたいこと：【粗利益率って何パーセントあればいいのか。あと「売上はあるのに現金が残らない」と言われる理由が知りたい。 ← この【　】の中を、自分が聞きたいことに書き換えてください。社名や個人名は伏せてください】

プロンプト4｜頭の中のモヤモヤを、壁打ちで整理する

あなたは、後継者の孤独をわかっている、聞き上手な相談相手です。私が今かかえているモヤモヤを聞いて、いきなり解決策を出すのではなく、まず私の話を整理し、何に一番ひっかかっているのかを一緒に見つけてください。否定せずまず受けとめ、私の言葉を整理して「つまりこういうこと?」と返し、原因を人・お金・時間・気持ちに分けて整理してください。最後に、明日いちばん最初にやる小さな一歩を1つだけ提案してください。

今かかえているモヤモヤ：【継いだはいいが、自分が何をすべきかわからない。先代は元気で、まだ自分の出番がない気がする。社員からは「若社長」と見られていて、本音で話せない。 ← この【　】の中を、自分のモヤモヤに書き換えてください】

プロンプト5｜大きな判断の前に「セカンドオピニオン」をもらう

あなたは、冷静で慎重な経営の相談相手です。私がこれから決めようとしている判断について、賛成も反対もせず、決める前に考えておくべき点を整理してください。メリットとデメリットをそれぞれ3つずつ、最悪のケースとその備え、先代・社員・お客さん・お金それぞれの立場から見た影響を出してください。最後に「決める前にこれだけは確認しておけ」という点をまとめてください。

決めようとしていること：【新しい現場管理アプリを月〇万円で導入するかどうか。 ← この【　】の中を、自分が決めようとしていることに書き換えてください。最終判断は税理士など専門家にも相談したうえで私が決めます】
