現場スマホAIプロンプト集

こんにちは、HEALTH ARCHIのHIDE（佐野英人）です。一級建築士として、設計と現場監督を17年やってきました。LINE登録ありがとうございます。

このページは、現場で動く職人さん・一人親方さんのための「スマホで使えるAIプロンプト集」です。パソコンは要りません。スマホにAIアプリ（Gemini / ChatGPT / Claude のどれか・無料で入ります）を1つ入れて、下のプロンプトをコピーして送るだけ。日報・報告・連絡・段取りといった「手を止めて頭を使う面倒ごと」を、AIに下書きさせる道具です。

私自身、現場でずっと「図面引いて、見積って、施主に説明して」をやってきた人間なので、机上の話ではなく「現場が終わってクタクタの夜に、これがあったら楽だったな」を基準に選びました。

先に、大事なお願い（30秒）
AIが出すのは、あくまで「下書き」です。報告の文章も、材料のリストも、そのまま信じきらず、最後はご自分の目で確かめてください。特に、お金・数量・施主への約束に関わる部分は、必ず自分で検算・確認してから使ってください。「AIは下書き、確かめるのは人の仕事」——これだけ守ってもらえれば大丈夫です。
使い方（はじめての方へ）
  1. スマホに無料のAIアプリを1つ入れる（おすすめ：Gemini か ChatGPT。アプリストアで検索）
  2. 下のプロンプトの「コピー」ボタンを押す（枠ごとコピーされます）
  3. AIアプリの入力欄に貼り付ける
  4. 文中の【　】の部分を、自分の現場のことに書き換える（中の例文を消して、自分のことを書くだけ）
  5. 送信 → 下書きが返ってくる → 直したいところは「ここをもっと短く」などと追加で頼む

写真を送れるアプリなら、現場写真を一緒に添えると精度が上がります。

プロンプト1｜作業日報・報告を3分で仕上げる

枠をコピーして、【　】の中を今日の作業に書き換えて送るだけ。

あなたは建設現場の職長です。私が伝える今日の作業内容を、元請けや会社に提出できる、きちんとした作業日報の文章に整えてください。「本日の作業」「進捗」「明日の予定」「連絡事項」の見出しで分け、天候や人員で気づいた点があれば最後に「特記」として足してください。専門用語はそのまま残し、丁寧だが固すぎない、A4半分くらいの分量で。

今日やったこと：【1階LDKの石膏ボード貼り8割。電気屋さんが配線、明日も来る。雨で外部はストップ。人員は大工2人と応援1人。 ← この【　】の中を、自分の今日の作業に書き換えてください】

プロンプト2｜元請け・施主への連絡を、角が立たない文章にする

あなたは現場経験の長い、言葉づかいの丁寧な職人です。私が伝えたい内容を、元請け（または施主）にLINEやメールで送る、失礼にならず、でも言いたいことはきちんと伝わる短い文章にしてください。相手を立てつつ、こちらの事情も角が立たないように、言い訳がましくならないように。最後に前向きな一言で締めてください。

伝えたいこと：【材料の入荷が遅れていて、来週の工程が2〜3日ずれそう。こちらのミスではないが、施主に先に知らせておきたい。代わりにできる作業から先に進めるつもり。 ← この【　】の中を、自分の伝えたいことに書き換えてください】

プロンプト3｜知らない言葉・新しい工法をその場で教えてもらう

私は建設現場で働く職人です。下の言葉（または工法・材料）について、現場の人間にわかるように、かみくだいて説明してください。小学生に教えるくらいやさしく、でも現場で恥をかかない正確さで。「何のために使うのか」「使うときの注意点」「よくある失敗」も一言ずつ。専門用語を使うときは、そのつどカッコでやさしい言い換えを添えてください。

調べたいこと：【気密測定（C値）って何か。 ← この【　】の中を、自分が知りたい言葉・工法・材料に書き換えてください】

プロンプト4｜簡単な見積り・請求の文面と、金額の伝え方

あなたは一人親方の相談相手です。私がやった工事の内容と希望金額をもとに、元請けや施主に出す「見積り（または請求）の文面」を作ってください。項目・数量・単価・金額が並ぶ見やすい形にし、追加工事があった場合はなぜ必要だったかを一言そえてください。あわせて、値切られたときに安売りせず・でも関係を壊さずに返す一言も提案してください。

工事の内容と希望金額：【〇〇邸の内装造作、3人で4日。材料費は別途〇万円。追加で棚を2つ作った。 ← この【　】の中を、自分の工事内容に書き換えてください】

プロンプト5｜段取りと「買い忘れ・持ち忘れ」チェックリスト

あなたは段取り上手な現場監督です。私がこれからやる作業の内容から、「必要な材料・道具・副資材」のチェックリストと、当日の段取り（やる順番）を、抜けがないように作ってください。現場で「あれ忘れた」が起きやすいもの（ビス・コーキング・養生材など）も念のため入れ、午前・午後でやる順番を分けてください。天候や搬入で気をつける点があれば最後に一言。

これからやる作業：【木曜に〇〇邸でフローリング貼り、6畳2部屋。材料は前日搬入予定。応援が1人来る。 ← この【　】の中を、自分がやる作業に書き換えてください】
